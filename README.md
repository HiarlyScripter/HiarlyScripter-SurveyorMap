## Portugues

SurveyorMap e um mod original de R.E.P.O. para BepInEx feito por HiarlyScripter. Ele adiciona um minimapa HUD client-side configuravel, com marcadores opcionais de inimigos e modo de edicao in-game.

O README completo usado no pacote fica em `package/README.md`. O changelog do pacote fica em `package/CHANGELOG.md`.

## English

SurveyorMap is an original R.E.P.O. BepInEx mod by HiarlyScripter. It adds a configurable client-side HUD minimap with optional enemy markers and in-game edit mode.

The full package README is in `package/README.md`. The package changelog is in `package/CHANGELOG.md`.
